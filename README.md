# Automated Docker Server

An Ansible project for automating the setup and deployment of a Docker-based server.

## Lab

The project currently uses an Ubuntu 24.04 VM managed with Multipass.

- Controller: macOS
- Managed Node: Ubuntu 24.04
- Host: `app-server`

## Ansible

Ansible is installed on the macOS host.

Check the installation:

```bash
ansible --version
```
